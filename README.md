# 共映 CoPlay

影视与音乐聚合网站，集中管理在线资源目录、本机视频、音乐、收藏与播放列表。使用 React / TypeScript / Vite 和 Express。当前按本地测试模式运行，放映室与公网分享已暂停。

## 启动

开发与构建需要 Node.js 22.12+ 和 pnpm；打包后的桌面版无需安装 Node.js。

```sh
pnpm install
pnpm dev
```

打开 **http://localhost:3000**。服务只监听 `127.0.0.1`，局域网与公网均不能直接访问。请求额外校验本机 Host，拒绝代理转发头。不会启动 Cloudflare 或其他隧道。

```sh
pnpm check       # TypeScript 检查
pnpm test        # 平台适配、下载、缓存、本地访问与回归测试
pnpm test:player # 构建后运行隔离的 Electron 播放界面回归测试
pnpm test:playlist # 音乐自动播放、编辑排序与四种队列规则的真实播放器测试
pnpm test:collections # 合集勾选、复制移动、下载及本机复用的真实界面测试
pnpm build      # 生成 dist/
pnpm start      # 提供本地生产构建与 API
```

可将 `.env.example` 复制为 `.env` 设置端口。修改服务端代码或环境变量后需重启服务。旧公网地址、TURN 与隧道环境变量不参与当前启动流程。

- B 站收藏夹 ml / favlist、视频分 P 和网易云歌单完整读取，支持进度、暂停继续、失败重试、筛选与勾选导入；新建或加入已有片单并去重。
- 编辑片单时可将条目复制或移动到其他片单，也可同时新建目标片单。
- Windows x64 免安装桌面版，独立应用窗口、原生保存对话框、下载进度与任务栏进度、持久收藏与缓存。
- 音乐点开即进入播放；本地音频与音频直链自动开始，网易云官方播放器启用自动播放参数。QQ 音乐使用修复后的官方地址，并提示在其播放器内点击播放。
- 收藏、播放历史与片单在本机保存；片单播放按钮和规则选择位于左侧，开启编辑模式后支持拖动或上下箭头排序、移除内容，顺序自动保存。
- 播放规则包括列表播放、随机播放、列表循环、单曲循环；规则记住上次选择。随机播放按轮遍历，上一项 / 下一项沿实际播放历史切换。
- 资源详情、官方嵌入播放器、媒体直链播放、共映社区评论。评论保存在服务端 `data/comments.json`。
- 放映室、P2P、语音相关代码暂时保留，当前入口与服务端接口关闭，不进行联网观看测试。
- 桌面与手机布局、键盘操作、弹窗焦点约束与 Escape 关闭、错误及空状态。

## Windows 桌面版

直接双击 `release/CoPlay-1.4.2-win-x64.exe`，无需安装 Node.js 或另起服务。它内置 Electron、前端与服务端，使用专属本机地址 `http://127.0.0.1:36743`；如果该端口已被其他程序占用，会显示原因并退出，不会连接其他服务。网页开发服务仍可使用 3000 端口。

桌面数据保存在 `%APPDATA%/CoPlay/`，目录缓存和评论位于其 `data/`，收藏与片单位于独立的应用存储。关闭再打开会保留数据；与浏览器 localhost:3000 的数据相互独立。本地媒体仍通过文件选择获得读取权，重新打开应用后需要重新选择文件。

```sh
pnpm desktop:runtime   # 首次开发时安装 Electron 运行时
pnpm desktop           # 构建网页并启动桌面开发版
pnpm desktop:pack      # 生成 Windows x64 免安装 EXE
pnpm desktop:unpacked  # 生成 release/win-unpacked/ 调试目录
```

桌面页面启用沙箱、上下文隔离与 CSP，网页不具备 Node.js 权限；拒绝麦克风等权限，外部来源链接通过系统浏览器打开。只支持从本机下载接口发起原生下载。构建未配置代码签名证书。

## B 站与音乐使用

1. 在资源广场的“有链接，直接看”输入 `BV1B7411m7LV`、完整 B 站链接或 `b23.tv` 短链接，即可读取标题、封面、作者和统计并打开详情。带 `?p=2` 的链接会定位相应分 P，详情可切换选集。
2. 点击“立即播放”优先使用本机播放器读取 B 站提供的公开 MP4，支持拖动进度。播放器底部显示当前清晰度，并提供“重试”“官方播放器 / 弹幕”和“在 B 站打开”；重试会保留已播放位置。需要保存时点击“准备下载”，再点击生成的 MP4 文件；桌面版弹出保存对话框并显示进度，网页版交给浏览器下载管理器。下载文件可通过“本地资源”再次打开。
3. 不输入关键词时展示 B 站热门视频、网易云与 QQ 音乐热歌榜。输入关键词后直接请求所选平台的搜索结果，支持歌名、歌手、视频关键词与下一页；网易云、QQ 音乐每页 24 首。指定作品也可使用链接直达。
4. 网易云支持 `https://music.163.com/song?id=186016`、`/#/song?id=186016` 和歌单链接。歌单读取曲目后可选曲。QQ 音乐支持 `https://y.qq.com/n/ryqq/songDetail/0039MnYb0qxYhV`、旧版 `/n/yqq/song/*.html`、移动端 songmid / songid 链接。

下载仅使用平台返回的公开 MP4，按当前可用清晰度标示（本机验证示例返回 360P）。未开放下载、付费、登录限制、试看片段或只提供不支持的媒体格式时显示具体原因；不绕过平台限制，不自动合并分段或转码。多段视频分别保存。网易云和 QQ 音乐通过官方播放器播放，可用曲目与试听长度取决于平台，目前不提供音乐下载。

B 站本机播放只读取平台公开提供的完整 MP4，不依赖第三方嵌入页面。媒体按需传输，不保存为目录缓存或先整段下载；支持 HTTP Range 与视频末尾读取。播放和下载分别校验：公开视频可播放不代表允许下载。付费、登录限制、DRM、试看片段、多文件分段或不支持的格式会直接显示原因，保留重试与原站入口，不自动切换到可能显示“非常抱歉”的嵌入页。只有手动选择“官方播放器 / 弹幕”才加载官方页面。

番剧使用正确的剧集 `episodeId`，不再将番剧 BV 重定向当作普通视频嵌入；默认展示平台播放入口。若官方页面显示“非常抱歉”或需要登录，可在 B 站打开对应剧集。网页侧栏显示完整版本号，入口 HTML 禁止缓存；1.4.2 的新页面可通过 `http://localhost:3000/?v=1.4.2` 打开。

## 音乐与播放列表

音乐卡片点开即可进入播放器，无需再点详情页的“立即播放”。本地音频和媒体直链会自动开始；网易云的已收藏旧链接也会在播放时启用自动播放参数。QQ 音乐旧地址自动升级到 `/n2/m/outchain/player/index.html`，其官方播放器当前仍需点击内部播放键。自动播放最终受浏览器和平台权限约束，本机音频被浏览器阻止时会显示“点击继续播放”。

进入左侧的播放列表，在内容区左上方点击“播放列表”，或直接点击列表中的音乐，从该曲开始播放。右侧“编辑列表”进入编辑模式，可拖动左侧把手或点击上下箭头排序，也可移出内容；操作即时保存在本机，点击“完成编辑”返回浏览。排序期间展示完整列表，避免筛选或评分排序掩盖真实顺序。

列表页面和正在播放的队列均可选择规则，选择自动保存在本机：

- **列表播放**：从当前项顺序播放，最后一项结束后停止，可点击“重新播放”。
- **随机播放**：每轮遍历全部条目再重新打乱，连续两首不会相同；上一项沿实际播放历史返回。
- **列表循环**：顺序播放，末尾回到第一项。
- **单曲循环**：反复播放当前内容；上一项、下一项仍可主动切歌。

这些自动切换规则适用于原生音频、视频、本地文件及 B 站本机播放。跨域官方播放器不提供播放结束通知时，队列会提示手动切换，不能自动跨曲续播或由共映触发单曲循环；仍可使用上一项 / 下一项或点击队列条目。关闭弹窗即停止当前播放。

## 单个资源、合集导入与跨列表整理

进入播放列表后点“导入资源”（列表内或顶部按钮均可），可切换“网站链接 / 本地影片·音乐 / 合集·歌单”。链接和合集支持粘贴链接或 BV 号，点“读取资源”预览并勾选。默认导入当前列表，也可选择其他列表或新建列表。在“我的播放列表”页的顶部也可直接打开此入口。支持：

- 单个 B 站视频链接、BV 号、网易云单曲链接（含 `#/song?id=...`）、QQ 音乐单曲详情链接。
- MP4、MP3、M3U8 等视频 / 音频直链，以及原有资源导入器支持的 YouTube 或影片详情页。

- B 站收藏夹 `https://www.bilibili.com/list/ml716471605`，以及 `space.bilibili.com/.../favlist?fid=...`。
- 多分 P 的 B 站视频链接或 BV 号会列出分集供勾选；带 `?p=2` 等参数的链接只读取指定分集。分集保留独立身份和播放页码，与下载副本的关联保持一致。
- 网易云歌单 `https://music.163.com/#/playlist?id=446097951`，以及不带 `#` 的 playlist 链接。

单个资源显示一条可勾选结果；合集会自动遍历所有公开页面。网易云根据完整 `trackIds` 每批补齐 50 首详情，不把旧接口的前 10 首当作整个歌单。界面显示来源总数、实际读取数、可选条目和失败原因；网络出错或暂停后可“继续读取”，先前勾选保留。失效或未返回详情的条目不可选；未返回的内容不生成虚构资源。平台私密、登录限制或接口限制会显示原因。

读取完成后可全选或按标题 / 作者筛选并逐项勾选，导入到已有片单或新建列表。只写入所选资源信息，不会批量下载媒体。已有条目保持位置，新条目按来源顺序追加，重复内容去重。

“本地影片 / 音乐”支持一次选择多个文件或拖放文件，可搜索文件名、全选或逐项勾选，再导入当前、其他或新建播放列表。同一文件自动去重；无效或空文件显示具体原因，其余文件仍可选择。切换导入方式保留各自的预览和勾选；取消弹窗不会保存本地资源，确认后才建立播放关联。文件不会上传。刷新后列表仍保留，需选择同一文件恢复播放。

“编辑列表”中每项的复制图标打开“复制或移动到其他播放列表”。复制保留原列表条目；移动先加入目标再从原列表移除；目标已有相同条目时不会重复添加。目标列表可直接新建，所有变更自动保存在本机。

## 播放列表搜索

“我的播放列表”页顶部搜索框按列表名称、描述筛选，搜索时留在当前页面。打开一个列表后，同一搜索框按内容标题、作者、平台和标签查找；切换“编辑列表”会保留关键词，排序和复制移动仍按资源实际位置执行。

打开播放队列后，播放器下方有独立的“搜索播放队列”输入框，可按标题、作者或来源定位条目。筛选期间当前媒体继续播放，上一项、下一项和自动播放仍遵守完整队列的播放规则；点击搜索结果会定位到它在队列中的原位置。清空输入可恢复全部条目，搜索不会改变已保存的列表。

队列搜索框旁的“定位当前播放”会清空筛选，滚动到并聚焦正在播放的条目。定位保持当前媒体及播放进度；切换上一项、下一项后，定位跟随新的当前条目，长队列和窄屏同样适用。

搜索忽略首尾空白、大小写与全半角差异，多个关键词用空格分隔时同时匹配。没有结果会显示空状态；这些列表搜索均在本机完成。

页面顶部的搜索、导入与用户栏固定在视口顶部；资源详情和其他弹窗的标题、关闭按钮固定在弹窗顶部，正文在其下方独立滚动，桌面和窄屏布局保持一致。

## 下载文件优先播放

从当前版本的“准备下载”链接完整下载 B 站视频时，服务会在流式传输过程中同时保存播放副本，不额外向来源重复下载。副本放在应用数据目录的 `downloaded-media/`，与下载管理器另存的文件分别占用磁盘空间。网页版本默认位于项目 `data/downloaded-media/`；桌面版本位于 `%APPDATA%/CoPlay/data/downloaded-media/`。索引使用平台视频 ID、分 P 和分段信息关联，跨播放列表和集合条目共用同一资源副本。

只有完整下载并原子写入索引的文件才用于播放；部分范围请求、下载中断和不完整文件不会登记。多文件分段需全部下载完成后才优先使用本机副本，播放时按分段顺序衔接。播放副本支持范围请求及拖动进度，并在播放器底部显示“正在播放已下载资源”。删除或损坏的文件不会伪装为可用资源，会使用在线来源或提供切换按钮；也可主动点击“使用在线来源”。替换已有副本后清理旧的应用副本，不触碰用户另存的文件。

旧版本下载的文件没有关联记录，可在资源详情点“关联已有下载文件”自行选择。这种关联只在当前页面会话有效，文件不上传，刷新后需重新选择；新版本完整下载的副本则持久保留。音乐平台目前仍使用官方播放器，不提供平台歌曲下载；用户已有的音频文件可以手动关联。

## 来源搜索

在顶部输入关键词即可搜索资源广场；从发现页输入也会进入广场。选择某个来源只查询该来源，选择“全部在线来源”则分别查询已启用的来源，完成后逐个显示。收藏、历史、片单与本地资源页仍搜索已有条目。

结果保留来源返回的顺序，包括歌手、别名等匹配，页面显示各来源已载入数量和可用的匹配总数。向下滚动逐批显示卡片，再点击“获取下一页搜索结果”请求源站下一页。没有结果时显示空状态，获取失败时保留该查询已有缓存并提供重试；不会用热门榜单冒充搜索结果。配置了搜索入口的来源还可点击“源站搜索”打开原网页。

B 站读取公开搜索页中的静态结果数据，支持分页，不执行页面脚本。网易云、QQ 音乐请求各自的歌曲搜索接口。人人电影网只读取搜索结果区域，排除侧栏推荐，缺少封面的结果仍可显示。AGE 保留源站返回的别名作品。Apple 请求官方关键词搜索接口，从最多 200 条返回内容中提取电影并分页，其数量不是全站电影总数。其他目录沿用各自的搜索接口。

## 内容与平台接入

资源广场使用真实在线目录。人人电影网接入 `https://www.rrdynb.com/index.html` 的电影、剧集与动漫卡片及搜索入口，首批实测 88 条。其网盘资源通过原站获取，目录卡片不表示本站已有完整片源。Internet Archive 详情按需读取公开 MP4 / WebM 版本；TVmaze、Apple 和 Jikan 主要提供元数据与来源入口。其他来源失败时仍展示成功返回的内容，不填造数量和评分。

“管理来源”可添加网页目录或兼容苹果 CMS 的 JSON API。网页支持普通图片、懒加载、背景封面、同站下一页、公开媒体标签与 JSON-LD；搜索模板用 `{query}` 和 `{page}`。网页来源未配置搜索模板时仍可浏览目录，搜索会提示补充配置。JSON 接口读取 `ac=detail`、`wd`、`pg`、`ids` 与分集地址。配置保存在 `data/sources.json`。服务端不执行站点脚本，校验 DNS 与重定向，阻止内网抓取。

AGE 使用其[域名发布页](https://github.com/agefanscom/website)公布的 `agedm.io`，已适配首页封面与标题分开的卡片结构，以及 `/search?query={query}&page={page}` 搜索和分页。2026-10-23 本机实测首页 20 条，搜索“海贼王”第一页 24 条；保留原站匹配到的别名作品。Node 支持系统证书读取时，会合并默认与系统信任库，仍验证证书与主机名。

Jikan 的接口地址与解析方式有效，但当前网络连接超时，暂不能获取新目录。DNS、连接与重定向默认合计最多等待 8 秒，网页关键词搜索放宽至 12 秒；失败冷却至少 60 秒，手动重试可重新发起。失败来源独立提示，不阻塞其他来源；已有目录缓存仍可浏览。

## 目录缓存与加载

资源广场打开时先读取浏览器目录缓存，按来源更新超过 10 分钟的内容；本机服务会优先返回磁盘缓存，页面收到过期目录后再独立刷新该来源。刷新失败保留旧内容并显示原因。缓存保存的是标题、封面地址、来源链接等元数据，不下载影视或音乐文件。

- 浏览器缓存使用 `coplay:catalog-cache:v1`，最多 40 页、2 MB；本机服务使用 `data/catalog-cache.json`，最多 100 页、12 MB。两层缓存均保留最多 7 天，并自动淘汰较早内容。
- 展开“本地目录缓存”可查看两层缓存的页数、大小与更新时间，也可逐个来源更新或清理目录缓存。清理不会删除收藏、片单、历史、本地文件或评论。
- 工具栏刷新会重新获取当前选择的来源；来源修改后使旧目录失效。切换搜索、离开页面或清理缓存会丢弃旧请求的迟到结果，服务端也阻止失效请求写回。
- 1.2 版为关键词缓存增加版本标记，自动忽略旧版热门榜单筛选结果；升级后首次搜索直接获取源站结果，无需手动清理缓存。
- 已取得的卡片每批增加 24 张；需要更多在线结果时点击“获取下一页内容”，只请求仍有下一页的来源。滚动观察器不可用时可手动“继续显示”。

本机接口实测首批目录约 1.5 秒返回，5 个可用来源共 260 条；总时长仍受失败来源的超时影响，但页面逐个显示已经返回的内容。实际时间随来源与网络变化。

首页影视卡片是**精选展示数据**，推荐分不是实时平台评分。有预告片的条目播放预告片，其他条目跳转来源平台。完整影视作品可通过用户拥有播放权限的媒体直链导入。内置《大雄兔》和《辛特尔》预告片来自 Blender 开放电影，包含来源及 CC BY 3.0 署名，示例媒体由 W3C 托管。

B 站公开 MP4 使用本机播放器，并保留[官方外链播放器](https://player.bilibili.com/)作为可切换的播放方式。网易云音乐与 QQ 音乐采用官方 outchain 播放器，YouTube 使用官方嵌入播放器。平台内容可能需要登录、区域可用性或授权；本站不会绕过平台访问控制，也不提供付费内容解析。

媒体直链、HLS 与 B 站公开 MP4 使用本地页面内的播放器；其他平台采用其嵌入播放器。播放器能否读取媒体取决于来源可用性、跨域设置与浏览器编码支持。

来源平台的元数据可能因上游限制获取失败；已有缓存继续保留，新导入显示错误原因，不生成虚假统计。目前聚合平台统计数，不抓取平台的评论全文或历史弹幕；共映社区评论、房间弹幕与来源平台数据相互独立。

## 本地观看与测试边界

进入“本地资源 → 打开本地文件”，或“导入资源 → 本地影片 / 音乐”。选择非空视频或音频，支持最大 100 GiB 文件。文件通过浏览器 File / Blob 读取，不完整读入内存、不上传；服务端只处理在线目录与应用数据。

推荐 H.264/AAC MP4、WebM、MP3。无转码功能，MKV 等封装或特殊编码能否播放由浏览器决定。刷新后文件条目保留，浏览器需重新选择同一文件获得访问权，通过大小与文件指纹校验。收藏、片单与播放历史仍在当前浏览器保存。

当前服务不提供远程邀请、局域网入口、WebRTC 协商或公网连接管理。`/api/share/*` 和放映室接口返回已暂停状态。资源聚合仍会主动访问用户所选的公开来源。

共映社区评论保存于 `data/comments.json`；来源配置保存于 `data/sources.json`。旧房间快照保留在磁盘，当前不加载或修改。收藏与片单不是云账号数据。
